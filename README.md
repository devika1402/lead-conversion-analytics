Lead-to-Member Conversion Analytics System
**Technologies:** PostgreSQL, Docker, Python, REST APIs, SQL, Dashboard Design

Built an end-to-end analytics pipeline for tracking gym lead conversions, staff performance, and revenue milestones.

**Features:**
- Normalized relational schema design with comprehensive ER diagrams
- Dockerized PostgreSQL database for reproducible deployment
- Python ETL pipeline consuming REST API endpoints
- Complex SQL analytics: revenue milestones, monthly staff rankings, conversion rates
- Interactive dashboard prototype design with KPIs and filtering capabilities

**Dataset:** 90+ leads, 3+ months of activity, multiple salespeople

**Skills Demonstrated:** Data modeling, ETL development, SQL, Docker, API integration, dashboard design
